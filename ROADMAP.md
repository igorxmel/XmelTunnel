# Roadmap

## 0.2.0 (in progress)

- [x] Routing mode: the whole PC by rules on top of any VPN client (sing-box TUN)
- [x] Unified profiles: sites, programs, folders and subnets, each profile with its target (your server, VPN, direct)
- [x] Self-update for both the installer and the portable build
- [x] Settings: theme, scale, start options; quick start on first run; the server is optional
- [ ] Fresh screenshots, README and social images (last, after all features)

## Next

- [x] Sharing your server: invite links or codes for friends (their own key, no SSH or root), and an admin panel
      to add, rename, pause, remove people and see their traffic
- [x] Built-in VPN client: servers from a subscription link (VLESS/Reality, VMess, Trojan, Hysteria2, TUIC,
      Shadowsocks), so a separate VPN client is optional
- [x] Server ping (a real request through each server, real exit country), filters and sorting: latency and availability of each server, pick the fastest

## Later

- [ ] macOS and Linux
- [ ] Android and iOS
